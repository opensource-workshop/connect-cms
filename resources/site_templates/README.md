# サイトひな型の追加

`resources/site_templates/<id>/template.json` を追加すると、サイト管理の「サイトひな型」に自動表示されます。PHPや設定ファイルへの登録は不要です。候補はIDの昇順に並びます。

IDは英小文字で始まり、英小文字・数字・ハイフンで100文字以内にします。ディレクトリ名とJSONの `id` を一致させてください。既存の `school-basic/template.json` を元に作成できます。

## 定義

- `schema_version`: `1`
- `id`、`name`、`description`: 識別子・表示名・説明
- `required_plugins`: 使用するプラグイン。`contents`、`menus`、`blogs`、`calendars` に対応します。バケツとフレームに使用する種類をすべて含めます。
- `pages`: ページの論理キー・名前・URL・親キー・レイアウト。先頭は `home`、URL `/`、親は `null` とします。
- `buckets`: コンテンツの論理キー・名前・プラグイン。同じキーを複数フレームから参照するとデータを共有します。
- `frames`: ページ・エリア・バケツ・表示テンプレート・表示順。メニューはバケツを `null` にします。
- `menus`: メニューフレームと、表示するページのキー一覧。
- `contents`: 固定記事のバケツとHTML本文。`{{site_name}}` は入力したサイト名をHTMLエスケープして置換します。

`buckets`、`menus`、`contents` は使用しない場合も空配列 `[]` として記載してください。ページは最大50件、バケツは100件、フレームは200件です。JSON全体は8MiB、固定記事の本文合計は1MiB以下にします。

ホームの `layout` は `ヘッダー|左|右|フッター` を各 `0` / `1` で指定します。中央は常に表示されます。例: `0|0|0|0` は中央のみ、`1|1|0|1` はヘッダー・左・中央・フッターです。他のページの `layout` は `null` とし、ホームのレイアウトを継承します。表示しないエリアにはフレームを配置しないでください。

ブログのフレームには `"view_count": 8` のように表示件数（整数1～100）を任意で指定できます。省略時はホーム5件、他ページ15件です。他のプラグインでは指定できません。

表示テンプレートはメニューの `default` / `tab`、他のプラグインの `default` に対応します。

## 確認と運用

不正なJSONやID不一致の候補は利用不可として表示され、正常な候補は引き続き利用できます。テンプレートディレクトリ外を指すシンボリックリンクは読み込めません。

JSONは開発者がレビューして配置する信頼済みファイルです。HTML本文は公開されるため内容を確認してください。PHP・Bladeとしては実行しません。管理画面からのアップロードには対応していません。

追加後は初期状態の専用確認DBで、一覧表示・確認・適用・公開画面・編集を確認してください。確認後にJSONを変更・削除すると適用は拒否され、再確認が必要です。適用済みサイトのデータは、JSONの変更・削除では更新されません。
